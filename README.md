# Java To-Do List Web Application

A simple task management application developed as a Java project.

## Features
- Add tasks
- View tasks
- Mark tasks as completed
- Mark tasks as incomplete
- Delete tasks

## Technologies Used
- Java
- Jakarta Servlets
- Apache Tomcat 10.1
- MySQL
- JDBC
- HTML
- CSS
- Eclipse IDE

## Database
Database name: todo
Table name: tasks

## How to Run
1. Import the project into Eclipse.
2. Set up MySQL.
3. Import todo.sql into phpMyAdmin.
4. Configure Apache Tomcat.
5. Run the project on the server.
